Repo audited: `/home/mark/projects/JPC/space-v2-refactor` @ `4ab858a3` (read-only; nothing in the repo was changed).
Scope: `apps/mobile/app`, `apps/mobile/src` (tests excluded from metrics), `packages/shared/src`.
CLAUDE.md conventions treated as deliberate and **not** flagged: relative imports / no `@/` alias, non-route files outside `app/`, `src/screens/<screen>/` sections, Zod-parsing hooks in `src/hooks/`, `query-keys.ts` factories, `src/design/` kit, pull-refresh workaround, keyboard inset/offset helpers, singular tabs routers, `public-id.ts` without nanoid.

- `shared-unused.js` – `packages/shared` exports referenced by no consumer (mobile, backend, other shared files). Output: `shared-unused.txt`.
